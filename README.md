# 星星计划 StarshinePlan

基本独立于 Mindustry 的mod。\
注重mod内平衡。 \
大概偏向工业？对于战斗难度方面进行史诗级增加。（当然早期版本不会很难）\
对了，mod里的那个单位（未完成）数值与机制不参与平衡，那个不会成为敌人，也无法制造，那是最终关卡的奖励单位。

## 当前进度

电力改革：改变电力系统，增加电压等级这一概念。

## 计划与未来
1. 电力改革：改变电力系统，增加电压等级这一概念。
2. 新工业一：先消耗物品与液体再生产。包括全部消耗物品的建筑
3. 新工业二：并行生产。
4. 新工业三：多物品生产。（必吃榜）
5. 建造范围：建造范围有限，超出范围减速。
6. 修复消耗：修理建造需要消耗物品，有代价修复。
7. 单位消耗：单位运行时消耗物品，有代价使用单位。（当然，不限单位数）
8. 战斗消耗：单位武器会消耗物品。
9. 还没想出来...

其核心就是，工业为战争，战争极其消耗资源。

## 备注
本mod仅支持159.3及以上版本。\
编写过程中未考虑与原版及其他 mod 的兼容性，崩了就别怪我了。
